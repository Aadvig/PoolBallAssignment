# Pool Ball Detection and Classification

This repository contains the code developed for my Computer Vision assignment at Trinity College Dublin. The objective was to detect and classify pool balls from images using C++ and OpenCV.

The project explores several computer vision techniques, including perspective transformation, mean-shift segmentation, Canny edge detection, Hough transforms, watershed segmentation, background thresholding, and colour classification.

## Development History

The majority of the commits were uploaded in the order in which the project was developed. However, some experimental implementations were not originally saved to GitHub and were instead retained in my Notion notes.

These earlier attempts were subsequently recovered and added to the repository, resulting in some commits appearing out of chronological order. Consequently, the commit history broadly reflects the development process but does not represent an exact chronological record.

The latest version on the `main` branch contains the final implementation of the pool ball detection and classification algorithm updated with the most recent ground truth.
